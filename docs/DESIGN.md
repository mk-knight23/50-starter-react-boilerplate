# Design System: 50-starter-react-boilerplate

## Visual Philosophy
The design follows a **Fully Animated / Motion-heavy** aesthetic. Stunning animations with violet/fuchsia gradients on a deep slate background.

## Design Patterns
- **Motion First**: Animations are first-class citizens
- **Ambient Motion**: Subtle continuous animations throughout
- **Gradient Accents**: Violet to fuchsia gradient highlights
- **Deep Background**: Slate-950 base with glassmorphic overlays

## Color Palette
- **Background**: Slate-950 (#020617)
- **Primary**: Violet-500 (#8b5cf6)
- **Secondary**: Fuchsia-500 (#d946ef)
- **Text**: White with 60% opacity variants

## Typography
- **Display**: Inter with tight tracking for headlines
- **Body**: Inter with relaxed leading for readability
- **Mono**: JetBrains Mono for code sections
